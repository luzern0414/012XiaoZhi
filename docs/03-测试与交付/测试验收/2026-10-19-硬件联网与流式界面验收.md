## 实体屏幕与物理语音的范围

实体设备已联网，但尚无现场确认其麦克风、扬声器或屏幕的实际呈现效果。电脑播放唤醒语没有触发可观察的设备语音连接，不能据此断言设备麦克风异常。

保留原厂屏幕驱动，继续使用原生 `stt` 和 `tts sentence_start` 文本协议；浏览器支持模型增量流，原厂硬件屏幕目前仍依赖原生分句协议。没有编译或烧录新的板级固件。

为招呼语另生成 `data/hardware/greeting.jpg`，通过原厂扩展配置提供图片地址，但设备尚未请求该图片，故**没有将实体屏幕招呼语标记为成功**。网页招呼语已确认显示，截图在 `data/acceptance/greeting-page.jpg`。

## 运行与恢复

`scripts/start-server.ps1 -Background` 启动语音服务并确保 IoT 服务运行；`scripts/start-web.ps1` 启动前端。停止时分别使用 `stop-web.ps1`、`stop-server.ps1`、`stop-iot.ps1`。重启电脑后需重新启动，当前未设置开机自启。

密钥和 MQTT 密码保存在忽略入 Git 的 `config/local.*`。备份、原始日志和 NVS 解析包含设备私密配置，仅放在忽略入 Git 的 `data/`，不应对外分享。

若需要回退硬件连接配置，使用备份的 `nvs.bin` 恢复 0x9000 分区即可回到原始 NVS；不必全片擦除或重刷屏幕资源。回退会重启设备，需在明确执行回退时操作。

当前主机和硬件 IP 来自 DHCP。地址变化时应同步调整设备 OTA、服务端 WebSocket 通告、原厂扩展适配、MQTT 监听及设备防火墙地址，再验证实际请求；建议在路由器中为这两个 MAC 保留地址。
