# 硬件接入与流式界面

用户已授权直接写入硬件和调整联网配置。本阶段保留原厂屏幕、音频和板级驱动，在完整 Flash 备份后仅调整 NVS 连接配置，避免使用未经确认的板型固件。

网页采用浅色、单列对话、紧凑状态栏和固定输入框。文本直接来自模型流式响应，提供停止、重新连接、语音输入与语音播放。密钥保留在服务端。使用真实连接状态标识硬件在线，不将 USB 已插入等同于网络在线。

服务端通过项目自有连接适配器给声明 `features.text_stream` 的客户端发送 `text_stream start/delta/end/error`，携带请求 ID，逐连接隔离，取消后不再转发旧请求。硬件继续接收原生 `stt` 与 `tts sentence_start` 文字，保留现有屏幕驱动。

实施顺序：备份与校验 → 检查 NVS 和网络 → 修改并读回连接配置 → 重启观察 → 网页流式对话和音频验收 → 记录物理硬件可验证范围。
